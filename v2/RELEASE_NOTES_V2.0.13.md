# XboxControllerHotkey V2.0.13

## Features
- Added an option to skip first-run controller setup and launch the app immediately.
- Added a preferred connection page to the in-app shortcut configuration flow.
- Added a home-screen shortcut to open the Windows-configured Captures folder.

## Improvements
- First-run setup dismissal is remembered, while connection preferences remain available later from the popover.
- Captures folder lookup uses the Windows Known Folder API so custom save locations are respected.

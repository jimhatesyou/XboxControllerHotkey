# XboxControllerHotkey V2.0.5

- Added Windows Plug and Play parent-chain transport detection for USB, Xbox Wireless Adapter, and Bluetooth.
- Corrected connection value alignment.
- Normalized GitHub release tags so the About page displays one `v` prefix.
- Added a silent startup release check with an opt-in update prompt.
- Added portable EXE self-update with SHA-256 verification and a helper process to replace the running executable safely.
- Added a persistent setting to disable automatic startup update prompts; manual checks remain available in About.
